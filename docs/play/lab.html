03 / UNITY C# · SOURCE-BASED EXPLANATION

Links carry order. An index carries membership.

Membership index{ }

The nodes below mirror the fixture's tile order as an illustration. Unity uses DoublyLinkedList<Card>; the browser above uses arrays. Moving these browser tiles does not execute C#.

O(1) pointer rewiring

Given a valid node or an endpoint, changing adjacent links takes fixed pointer work.

Expected O(1) membership

A hash index avoids walking every node. Hash operations have collision and resizing costs.

O(m) full append

Joining endpoints is constant pointer work; merging the appended list's membership entries still visits m values.

O(n) traversal

Drawing, validating or finding an unindexed value requires visiting the relevant nodes. A complete AI turn is not O(1).
